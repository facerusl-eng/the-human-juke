# The Human Jukebox - EPG (Electronic Promo Guide)

## One-liner
The Human Jukebox turns any live show into an interactive audience experience where guests request songs, vote tracks up in real time, and stay engaged from first note to last encore.

## Short concept pitch
The Human Jukebox is a live audience request and voting platform built for performers, hosts, and venues.

Audience members join from their phones, browse a curated song list, request songs, and vote on what should come next. The host keeps full control from the admin panel, while the queue updates live on audience and mirror screens.

Result: more engagement, better crowd energy, and a show that feels truly shared.

## What makes it different
- Live voting queue that reorders songs by audience demand
- Host-controlled event flow (go live, pause, end gig, moderation)
- Curated setlists to keep quality and style on brand
- Audience-friendly mobile flow with no app install required
- Real-time updates across audience, host, and display views

## Who it is for
- Solo artists and bands who want deeper audience interaction
- Event hosts who need structure without losing spontaneity
- Venues that want a modern, memorable live music experience
- Private events and corporate gigs where participation matters

## Simple how-it-works
1. Host creates a gig and chooses the setlist.
2. Audience scans a link and joins instantly.
3. Guests request songs and vote favorites up.
4. Host runs the queue and performs with full control.
5. The room stays engaged because everyone has a voice.

## Value statement
The Human Jukebox helps turn passive listeners into active participants, making live music more social, more dynamic, and more unforgettable.
